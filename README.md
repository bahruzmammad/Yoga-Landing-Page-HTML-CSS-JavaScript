# Yoga Landing Page

A responsive yoga landing page built with HTML, CSS, and JavaScript.

## Live Demo

https://yoga-landing-page-with-html-css-js.netlify.app/

## Features

* Responsive design
* Mobile navigation
* ScrollReveal animations
* Social media links

## Technologies

* HTML5
* CSS3
* JavaScript
* ScrollReveal.js
* Remix Icon
